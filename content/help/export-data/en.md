The file isn’t encrypted, so keep it somewhere safe. For a report to read or to show your doctor, use the [PDF report](/en/help/pdf-report).

On iPhone, the file holds your profile and goals, diary, library, recipes, own products and body measurements, but no photos. Importing replaces exactly this data on the device. You also find “Export debug log” there, which you only need if support asks for it.
