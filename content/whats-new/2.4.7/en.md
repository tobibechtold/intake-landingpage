## A clearer start with Intake AI

Intake AI now begins with a short, story-based onboarding. It explains the available options step by step, so you can understand the difference before deciding how you want to use AI in Intake.

The **Intake AI subscription** provides the complete, integrated food-logging experience with food-specific prompts, richer controls, and ongoing improvements.

With an **own API key (BYOK)**, you can instead connect Intake directly to your own OpenAI, Claude, or Gemini API account for the basic AI chat flow. Any API usage is handled under your provider's terms and pricing.

The new onboarding puts these differences into clearer context and makes it easier to choose the option that fits you.

## Smoother day-to-day use

This release also fixes several performance issues. We improved responsiveness in different parts of the app so everyday interactions feel smoother and more reliable.

You can find the full changelog [here](https://featurevoting.tobibechtold.dev/app/intake/changelog).
